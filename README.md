# travel-booking-website

Premium travel booking website scaffold for India tours.

## Highlights
- 20 frontend pages for tours/destinations/blogs/reviews/contact.
- Floating WhatsApp CTA and social integrations.
- Google + TripAdvisor review links and local review module.
- Multilingual UI support (EN, DE, ES, IT, FR).
- PHP/MySQL backend scaffolding with API and admin pages.
