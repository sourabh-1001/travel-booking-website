# Customization Guide

## Branding
- Update company name and contact details in `js/main.js` and page metadata.
- Replace social URLs and WhatsApp number in `config/settings.php`.

## Tours & Pricing
- Edit tour records in database (`tours` table) or through admin panel pages.
- Adjust package cards on `pages/tours.html` and destination pages.

## Language Strings
- Update `js/multilingual.js` and `languages` table entries for EN/DE/ES/IT/FR.

## SEO
- Set canonical domain values on all pages.
- Regenerate `sitemap.xml` after adding/removing pages.
